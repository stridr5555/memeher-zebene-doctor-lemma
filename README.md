# Memeher Zebene Doctor Lemma Ministry Website

A polished Next.js site for Ethiopian Orthodox teaching ministry.

## Features
- Light theme with blue accents and Ethiopian Orthodox-inspired iconographic motifs
- YouTube and Facebook ministry sections
- Respectful discussion/comments UI
- Admin login with HTTP-only cookie
- Dashboard with YouTube stats and recommendations
- Google Translate API route for Amharic translation

## Environment
Copy `.env.example` and configure:
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `ADMIN_SESSION_TOKEN`
- `YOUTUBE_API_KEY` or `GOOGLE_API_KEY`
- `GOOGLE_TRANSLATE_API_KEY` or `GOOGLE_API_KEY`

## Run
```bash
npm install
npm run build
npm run dev
```
